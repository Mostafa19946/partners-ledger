# دفتر الشركاء

نظام محاسبة شركاء بسيط: تسجيل دخول لكل شريك، حساب جاري، ومشاريع بإيرادات ومصروفات ونصيب كل شريك حسب نسبته.

## المتغيرات البيئية (Environment Variables) المطلوبة عند النشر

- `DATABASE_URL` — رابط الاتصال بقاعدة بيانات Postgres (يوفره Render تلقائيًا عند ربط قاعدة البيانات)
- `JWT_SECRET` — نص عشوائي طويل لتوقيع جلسات الدخول
- `ADMIN_USERNAME` — اسم مستخدم المدير الأول (افتراضي: admin)
- `ADMIN_PASSWORD` — كلمة مرور المدير الأول (افتراضي: admin123 — **غيّرها فورًا بعد أول دخول**)
- `ADMIN_NAME` — اسم المدير المعروض (اختياري)

## التشغيل محليًا

```bash
npm install
DATABASE_URL=postgres://... JWT_SECRET=some-secret npm start
```

يفتح على http://localhost:3000

## النشر على Render

1. أنشئ قاعدة بيانات Postgres جديدة.
2. أنشئ Web Service من هذا المستودع، بـ:
   - Runtime: Node
   - Build Command: `npm install`
   - Start Command: `npm start`
3. أضف متغيرات البيئة أعلاه (اربط `DATABASE_URL` بقاعدة البيانات التي أنشأتها).
4. بعد أول نشر، سجّل دخول بحساب المدير الافتراضي وغيّر كلمة المرور فورًا من صفحة "إعدادات حسابي".
